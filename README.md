# MTE544 Lab

Neel's MTE544 lab coursework.

## Branches

- `main`: repository overview and shared configuration.
- `lab1_neel`: Lab 1 motion control, sensor logging, and plotting code.

Switch to the lab branch to work with its code:

```bash
git switch lab1_neel
```

The Lab 1 starter is from [UW-MTE544/MTE544_student, LabOne](https://github.com/UW-MTE544/MTE544_student/tree/LabOne). Its original MIT license is preserved in `LICENSE`.

Generated recordings, Python caches, and local credentials are excluded from version control. Keep collected lab data separately for submission.
